# DPTV802 Interactive ROM Lab

This repository hosts the final browser-based DPTV802 range-of-motion learning lab published through GitHub Pages.

## Final activity set

- Elbow flexion tutorial
- Knee flexion
- Shoulder flexion
- Forearm pronation and supination
- Shoulder internal and external rotation
- Hip internal and external rotation
- Ankle dorsiflexion and plantarflexion

Cervical flexion and extension have been removed.

## Approved revisions

- Shoulder rotation uses the approved upper-body images with the torso parallel to the frame, prominent olecranon, and rigid forearm-hand motion from the humerus.
- Ankle activities use the approved neutral and dorsiflexion pictures and the final reduced plantarflexion picture.
- Forearm pronation and supination no longer include interactive goniometer placement, realignment, or placement scoring. They score only the forearm axis, stationary reference, and moving reference multiple-choice items while the right-front three-quarter images show rotation.

All other measurement activities retain their full scored workflows. Every documentation activity requires students to enter both the starting position and endpoint.
